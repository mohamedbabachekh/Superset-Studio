{# Everything this kit adds to Superset's own pages. Superset includes this file in `superset/spa.html` for every page it serves, which is the supported way in — no fork, no patched bundle. WHY IT IS CSS AND NOT A TEMPLATE. Superset 6.1 draws its sign-in page in React, so Flask-AppBuilder's `login_db.html` is never rendered (I replaced it first, and the stock page kept coming back). What is left is the page it does draw, and antd's structure is stable enough to take hold of: a card inside `main.ant-layout-content`, with the username field in it. EVERY RULE IS SCOPED to a page that has the sign-in field — `body:has(input#username)`. Measured, not assumed: antd renders those inputs with an id and NO name attribute, so a `[name=...]` scope matched nothing and the whole sheet sat inert on the page (2026-10-01). Nothing here can reach SQL Lab, a dashboard or Explore. And if a later Superset changes that structure, the rules simply stop matching and the stock page comes back: nothing breaks. The English in the card ("Sign in", "Enter your login and password below:") comes from Flask-AppBuilder, not from Superset's catalogue, so the French translation step does not reach it; it is replaced here. #}
